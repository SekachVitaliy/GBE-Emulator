# GBE-Emulator

An original Game Boy Advance emulator written from scratch in Rust and compiled to WebAssembly, built for the [GBA Eval](https://github.com/mechanize-work/gba-eval) engineering trial (10-function C ABI in `gba-eval/spec/ABI.md`, graded against Mesen2).

**Graded result: overall 0.9343** (procedural 0.800, gameplay replays 0.958, audio 0.997). The stub baseline scored 0.0085 and gba-eval's partial baseline about 0.53. The practical ceiling is about 0.96, because the corpus has no testcase for the `comprehensive` procedural subsystem.

The work was done by a team of AI agents (cpu, bus, ppu, apu, grader, plus an independent read-only code reviewer) orchestrated with [ruflo](https://github.com/ruvnet/ruflo) and Claude Code, with a shared module contract (`gba-emu/ARCH.md`).

|---|---|
| `gba-emu/` | the emulator crate (`src/`, `tests/`, `examples/`), build/grade scripts (`scripts/`), prebuilt `dist/gba_emu.wasm`, and all docs |

| `gba-emu/results/final/` | per-testcase JSON of the final graded run (WAV/PNG outputs omitted for size) |
| `.claude-flow/data/` | orchestration state: `checklist.json` (task list the autopilot worked through) and `scores.md` (one line per graded run, the score history) |
| `CLAUDE.md`, `.claude/settings.json`, `.mcp.json`, `package.json` | agent/orchestration configuration and dependency files (ruflo 3.72.1) |
| `docs/USAGE.md`, `docs/WORKFLOW.md` | wall-clock time, token usage and cost, how the work was organised |
| `docs/conversations/` | cleaned, readable export of the lead session and the subagents |
| `docs/raw-transcripts/` | redacted raw transcripts (lead, subagents, early sessions) |
| `docs/snapshots/` | twelve source snapshots, one per new best score |
| `docs/RECORDS.md` | what is included and what is not available, and why |

## Reproduce
Requirements: Rust with the `wasm32-unknown-unknown` target (via rustup), Node 22, and a checkout of `mechanize-work/gba-eval` as a **sibling folder named `gba-eval`** next to `gba-emu/` (it is not vendored here). Its `corpus/reference-cache/*.refcache` are git-LFS files: without git-lfs, regenerate them with `gba-emu/scripts/precompute.sh` (about 3 minutes). Then:

```bash
gba-emu/scripts/build.sh     # builds gba-emu/target/wasm32-unknown-unknown/release/gba_emu.wasm
gba-emu/scripts/grade.sh     # native grader, writes results/<timestamp>/ and appends a line to .claude-flow/data/scores.md
cd gba-emu && cargo test --release
```
Details, tool versions and caveats: `gba-emu/GRADING.md`, `gba-emu/README.md`.

## Not included
- `gba-eval/` (third-party benchmark, clone it separately) and the trial's task text.
- Version-control history (none exists); see `docs/RECORDS.md` for everything else that is unavailable.
- Local state: ruflo memory databases, the 89-agent default library generated by `ruflo init`, build outputs, large grader artifacts.
